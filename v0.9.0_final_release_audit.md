## 16. Remaining Limitations (By Design)

### Documented and Accepted
- HTTPS only - No SSH, file://, git@
- Existing configured remote only - No arbitrary URLs
- Existing remote branch only - No arbitrary refspecs
- Fast-forward only - History rewrites rejected
- No tags - Tracking refs only
- No submodules - Recursion suppressed
- No pull/merge/rebase - Fetch-only
- No automatic retry - Single network attempt
- Trusted user/global config only - Repository-local dangerous config rejected
- Does not control: OS proxy/DNS, trusted credential helpers, server behavior

## 17. Security Posture

### Threat Model Coverage
✓ URL redirection attacks → blocked via insteadOf detection
✓ Credential injection → blocked via repository-local helper rejection
✓ Header injection → blocked via repository-local extraHeader rejection
✓ Routing hijack → blocked via repository-local proxy rejection
✓ History rewrite → detected via fast-forward check

✓ Workspace contamination → prevented via fetch-only, no merge

- All validation before user approval
- No credential helper execution before approval
- No DNS/TCP/HTTP before approval

### Exactly-Once Network Semantics
- Single fetch attempt per approval
- No retry logic
- No automatic conflict resolution
